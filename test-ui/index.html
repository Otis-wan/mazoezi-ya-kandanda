How to make a dev key 
openssl ecparam -name prime256v1 -genkey -noout -out dev-private.pem
openssl pkcs8 -topk8 -nocrypt -in dev-private.pem -out dev-private-pkcs8.pem
openssl ec -in dev-private.pem -pubout -out dev-public.pem

Paste dev-private-pkcs8.pem above. Put dev-public.pem in AUTH_PUBLIC_KEY in .env (newlines as \n). Add this page's address to CORS_ORIGINS, for example http://localhost:8080. Serve the page with python3 -m http.server 8080 --directory test-ui.
